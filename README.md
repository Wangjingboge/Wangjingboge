## 关于我

我用了二十来年时间，只研究一件事：**普通人怎样才能用最低的成本，拿到市场的长期收益。**

- 985 数学系本硕出身，先后在中国银河证券、银华基金、方正富邦基金做金融产品研究与设计，做的是指数产品、FOF、目标养老产品这些"结构"上的活儿。
- 后来任集思录副总裁、创办合晶睿智，也是《中国 SmartBeta 50 人》成员。
- 编著、翻译了十余本资产配置与量化投资的书——从 MATLAB 到 Python，从风险均衡到动量策略，从博格到先锋集团。
- 现在 44 岁，在做一件更直接的事：**把"看估值、看温度、看资金"这件事，做成普通人点一下就能用的工具。**

名字的来源很直白：家住望京，偶像约翰·博格。所以叫望京博格——"约翰·博格的中国山寨版"，这话我自己说的。

## 我的投资观

**1. 成本是唯一确定的收益。** 费率省下来的 1%，是每年稳赚的 1%，比择时靠谱得多。

**2. 便宜的时候买，比买什么更重要。** 绝大多数人亏钱不是因为买错了标的，是因为在别人赚钱之后才进场。

**3. 别预测，去衡量。** 没人能预测市场。但估值分位、资金流向、盈利增速是可以算出来的，算出来就比拍脑袋强。

**4. 承认自己会亏。** 我今年浮亏两位数，一样每周贴出来。投资这件事，诚实比聪明值钱。
